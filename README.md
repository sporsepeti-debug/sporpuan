# Sporpuan

Kısa açıklama: Sporpuan projesi — sporla ilgili puanlama/skor takibi uygulaması. Bu repo, proje kaynak kodunu, kurulum ve çalıştırma talimatlarını içerir.

## Gereksinimler
- Node.js >= 16 (varsa)
- Python >= 3.8 (varsa)

## Kurulum
1. git clone git@github.com:sporsepeti-debug/sporpuan.git
2. cd sporpua n
3. (projeye göre) npm install veya pip install -r requirements.txt

## Çalıştırma
- npm start veya python main.py
